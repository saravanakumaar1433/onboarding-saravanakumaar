# Module 06 - GitHub Actions CI Pipeline

## Objective

Create a Continuous Integration pipeline to automatically validate changes using GitHub Actions.

## Concept Checkpoint

| Topic | Status |
| Workflow Triggers | Done |
| GitHub Runners | Done |
| Jobs and Steps | Done |
| Build and Test Pipeline | Done |

## Pipeline Features

- Trigger on Pull Requests to main
- Trigger on Push to main
- Checkout source code
- Setup Node.js environment
- Install dependencies
- Execute build step
- Execute test step
- Generate build artifact
- Upload artifact

## Workflow File

```text
.github/workflows/ci.yml
```
## Evidence

- CI workflow created
- Workflow committed to repository
- GitHub Actions pipeline configured
- Artifact publishing configured
